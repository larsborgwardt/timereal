`tests/rollen.mjs` startet in einer eigenen leeren Datenbank vor den übrigen Fällen. Der Test prüft Betriebsrechte, fehlende Administratorrechte für Betrieb, Erweiterungsausschluss, HTTP-Berechtigungen, direkte RLS-Gegenprobe mit eingeschränkter Rolle, Widerruf von Web-/Erweiterungssitzungen, unveränderten Wert ohne Widerruf und weiterlaufenden Timer. Konkurrierende gegenseitige Herabstufung und Sperre warten nachweislich beide vor der Sitzungssperre auf das gemeinsame Schloss. Nach Freigabe gewinnt eine Anfrage; die andere scheitert an der widerrufenen Sitzung. Ein aktiver Administrator bleibt erhalten. Die älteren Kontenabfragen aus 0.8.0 laufen auf dem ergänzten Schema weiter.

Die Browserprobe misst die ungespeicherte Rollenauswahl über einen echten Hintergrundabruf hinweg, Speichern und erneutes Anzeigen fremder Änderungen, eigene Kontosperre, Betriebsansicht ohne Konten-/Einladungsabrufe sowie 1280/390/320 Pixel mit regulärer und verdoppelter Schrift. [Desktop](rollen-2026-11-19/desktop.png) und [Mobil](rollen-2026-11-19/mobil.png) wurden einzeln am freigegebenen Zielbild geprüft. Die Aufnahmen stammen aus dem isolierten Vorlauf vor dem Versionsnachzug; der endgültige Gesamtlauf prüft 0.8.1. Die native Chromium-Erweiterung wurde nach dem neuen Websitzungsvertrag angepasst und erneut tatsächlich geladen.

Selbstprüfung: Datenbankrechte, Sitzungs-/Kontosperrreihenfolge, Eingabegrenzen, HTML-Escaping, Rollenentwurf bei Hintergrundabruf, Migration und Rückwärtskompatibilität am Code und den genannten Abläufen geprüft. Keine unabhängige Reviewrunde beauftragt. Apple-Design-Skill: `/home/hermes/.agents/skills/idb-apple-design/SKILL.md`, dessen lokale Upstream-Methodik und `references/hig/loading.md`; vorhandene Accessibility-/Layoutprobe weiterverwendet. ## Update

Über **Verwaltung → Updates → Status aktualisieren → Update vorbereiten → Sichern und installieren**. Neue Konten werden zunächst als Berater eingeladen. Anschließend kann ein Administrator unter **Verwaltung → Konten** die Rolle speichern. Betroffene Sitzungen werden abgemeldet; laufende Arbeit bleibt erhalten. Schema 7 ist additiv, API 1 und Betriebsprotokoll 1 bleiben kompatibel. Das mitgelieferte Erweiterungspaket blendet die nur im Web verfügbare Verwaltung aus.
