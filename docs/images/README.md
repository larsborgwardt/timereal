# Herkunft der Bildschirmbilder

Die PNG-Dateien sind unveränderte Aufnahmen der laufenden Timereal-Oberfläche aus den erfolgreichen Browserproben von 0.6.2 am 19. November 2026. Die Konten, Kunden und Buchungen stammen aus der getrennten Testdatenbank. Keine Aufnahme zeigt Daten aus Lars' Pilotcontainer.

| Datei | Erzeuger |
|---|---|
| `wochenuebersicht.png` | `tests/arbeitsablauf-browser.mjs`, Bildschirm `woche.png` |
| `buchungsvergleich.png` | `tests/arbeitsablauf-browser.mjs`, Bildschirm `vergleich.png` |
| `browsererweiterung.png` | `tests/erweiterung-browser.mjs`, Bildschirm `erweiterung-popup.png` |

Der [Versionsnachweis](https://github.com/larsborgwardt/timereal/blob/v0.6.2/nachweise/0.6.2.md) enthält den Testaufruf. Bilder im Verzeichnis `mockups` sind dagegen Zielentwürfe und keine Funktionsbelege.
